# เขตของคุณ — ฝั่งหน้าจอ

การอัปเกรด iVS จะไม่แตะโฟลเดอร์นี้

| อยากทำอะไร | แก้ที่ไหน |
|---|---|
| เพิ่มเมนูและหน้าจอใหม่ | `pages.ts` แล้วสร้าง `pages/<slug>.tsx` |
| เรียก API ของตัวเอง | `fetch("/api/custom/<ชื่อ>/...")` |

**อย่าแก้ `components/sidebar.tsx`** — ไฟล์นั้นถูกเขียนทับตอนอัปเกรด
เมนูที่ประกาศใน `pages.ts` จะไปโผล่ในแถบข้างเอง

หลังบ้านของคุณอยู่ที่ `backend/app/custom/` ดู README ในนั้น
