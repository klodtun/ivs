# sRGB ICC profile

`sRGB-v2-micro.icc` — 456 bytes, from
[saucecontrol/Compact-ICC-Profiles](https://github.com/saucecontrol/Compact-ICC-Profiles),
released into the public domain (CC0 1.0).

PDF/A requires an OutputIntent naming the colour space the document was
prepared for, so that colours reproduce the same way in ten years' time as
they do today. A full sRGB profile is ~3 KB; this compact one carries the same
sRGB v2 transform in 456 bytes.
